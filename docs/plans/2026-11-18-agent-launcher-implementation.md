# 本地Agent启动器实施计划

用户已澄清执行方式：代码只触发本地Agent并给出提示词，由Agent自行连接浏览器、调用数据库技能入库并整体核对。此前逐页采集适配器及强制JSON结果协议不再作为实现方向。

复用FastAPI、SQLAlchemy、Alembic、APScheduler和现有数据分析服务；继续已确认的feature/order-sync-and-mcp，不切分支、不合并。

1. TDD新增Agent任务/运行记录、自由提示词和命令参数、原生进程启动、日志与退出状态。内置dsh/Antigravity使用已授权完整权限；自定义命令原样执行，不加工具白名单、SQL只读或任务时长限制。
2. 新增项目数据库技能及可执行inspect/sql/ingest/reconcile工具；支持美团平台标识，保留现有订单关联及数量规则。启动器不调用采集/入库/核对逻辑，由Agent自主调用技能。
3. 接入现有worker的任务调度；新增网页管理/手动启动/日志和CLI入口。进程正常退出只表示结束，不自动宣称订单核对通过。
4. 用户已确认仅定时触发；没有钉钉功能或配置。
5. 使用本地可控Agent进程验证启动→数据库技能插入→核对→报告全链路，检查真实CLI参数、迁移、回归及UI；不声称没有登录凭据的商家后台已经联调。
